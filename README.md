# Paso a Paso

Application web pour apprendre l'espagnol du niveau A1 au C2 (CECRL) :
36 leçons thématiques, cartes de révision à répétition espacée,
entraînement de conjugaison (34 verbes, 15 temps) et prononciation audio.

Tout tient dans `index.html`, sans dépendance ni compte. La progression
est enregistrée dans le navigateur de chaque personne.

Sur iPhone : ouvrir l'adresse dans Safari, puis Partager → Sur l'écran d'accueil.
